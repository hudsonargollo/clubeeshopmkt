# Product Overview

ClubeeShopMkt is an Edge-Native Multi-Tenant Retail Operations Platform consisting of:

1. **Product Inventory Manager** - Backoffice system for shop staff to manage inventory via barcode scanning
2. **Frontend Webshop** - Mobile-first customer-facing storefront for browsing and ordering

## Core Capabilities

- Multi-tenant architecture supporting multiple shops on a single platform
- Real-time inventory synchronization across backoffice and webshop
- Barcode scanning via Honeywell MS9520 USB scanner and mobile camera fallback
- Two fulfillment modes: Takeout (scan-to-pickup) and Delivery
- Global search with PostgreSQL full-text search

## Key User Flows

- Staff scan barcodes to manage inventory and fulfill orders
- Customers browse products, add to cart, and checkout
- Takeout customers show QR code for pickup verification
- Delivery orders include address validation and routing
